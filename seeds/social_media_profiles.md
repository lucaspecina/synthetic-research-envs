# Seed: Social Media Usage Profiles and Wellbeing

## Type
Descriptive / exploratory / segmentation (scenario #14)

## Domain
Digital health / behavioral science / social media research

## Study design
Cross-sectional survey of 1000 users with screen time tracking, content
categorization, and self-reported wellbeing measures. No experimental
manipulation — the goal is to DESCRIBE patterns and identify vulnerable
groups, not test a specific hypothesis.

## Variables
- Daily screen time (hours)
- Pct time on video content
- Pct time on social/messaging
- Pct time on news/information
- Peak usage hour
- Age, gender
- Wellbeing score (validated scale)
- Productivity self-report
- Sleep quality score
- Number of social connections
- Content creation vs consumption ratio

## Key findings to inspire
- 3 main usage profiles: (1) moderate-diverse 40%, (2) intensive-social 25%,
  (3) nocturnal-news 15%, (4) low-use 20%
- Profile 2 (young, >4h/day, >60% social): wellbeing 1.5 SD below average
- Profile 3: productivity low, sleep disrupted, but wellbeing near average
- Screen time alone is poor predictor — CONTENT TYPE matters more
- Social media production (posting) associated with better wellbeing than
  passive consumption, even at same screen time

## Research questions
- Are there distinct usage profiles in the data?
- Which profile characteristics predict low wellbeing?
- Is total screen time or content type more predictive of outcomes?
- Does active (producing) vs passive (consuming) use matter?
- Which demographic groups are overrepresented in vulnerable profiles?

## Causal complexity
- This is NOT a causal study — it's descriptive/exploratory
- No single target variable: wellbeing, productivity, sleep are all outcomes
- Clustering is subjective: different numbers of clusters are valid
- Confounders everywhere: age affects both usage patterns and wellbeing
- The value is in DESCRIBING structure, not testing hypotheses
- Calibration: not over-interpreting clusters or claiming causation
