# autoresearch/ — Investigacion autonoma con loop empirico

Este directorio documenta las sesiones de autoresearch: ciclos autonomos de
debate + experimentacion + reflexion sobre el sistema SREG.

## Que es autoresearch

Loop continuo:
1. **Debatir** (Claude + Codex): identificar pregunta, formar hipotesis
2. **Probar** (E2E, scripts, SCM): ejecutar experimento concreto
3. **Ver resultados**: analizar output real, no especulativo
4. **Reflexionar**: que aprendimos? que cambia? documentar
5. **Repetir** hasta que el usuario interrumpa
